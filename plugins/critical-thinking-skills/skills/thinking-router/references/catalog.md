# Catalog — 8 Critical Skills

Ranked by evidence base × agent-scriptability × non-overlap (from `research/critical-thinking/plan.md`).

| Rank | Slug | Family | When to use | One-line artifact | Key refs |
|---|---|---|---|---|---|
| 1 | `evidence-appraisal` | Evaluation (Facione/Paul-Elder information) | A claim cites a source — how much is it worth? | Source scorecard + strength 1-5 + next probe | Facione 1990; Paul–Elder; Ioannidis 2005 |
| 2 | `argument-mapping` | Analysis | A paragraph sounds persuasive — does it follow? | Claim–grounds–warrant–backing map + validity tag | Toulmin 1958; Walton 2008 |
| 3 | `fallacy-bias-spotting` | Self-regulation | Draft feels right but might be systematically wrong | Annotated fallacy/bias sheet (Hit/Maybe/No) + de-bias | Kahneman 2011; Tversky & Kahneman 1974; Hamblin 1970 |
| 4 | `bayesian-updating` | Inference / Likelihood | Prior + new evidence → how much to move? | Prior → LR → posterior + base-rate flag + VOI | Bayes; Tetlock 2005/2015 |
| 5 | `socratic-elenchus` | Conceptual clarity | A key term is used but never defined | Term → definition → counterexample → operational definition | Paul & Elder 2006; Ennis 1996 |
| 6 | `steelman-red-team` | Fair-minded evaluation | Critique feels weak / strawman; need strongest counter | Steelman (strongest ¬P) + 5 attack vectors + falsifier | Paul–Elder; Zenko 2015; Tetlock; Popper |
| 7 | `calibration-forecasting` | Self-regulation | Confidence ≠ accuracy; need accountable forecasts | Brier-scored log + calibration curve + 3 live predictions | Tetlock & Gardner 2015; Brier 1950 |
| 8 | `decision-analysis` | Decision making | Choose under uncertainty with stakes | EV sheet (options × outcomes × p × u) + sensitivity + probe | Halpern Ch.10; Howard & Matheson 1984 |

## Decision tree

```
Need judgment?
 ├─ "is this source/claim worth how much?" → evidence-appraisal
 ├─ "does the reason support the claim?"  → argument-mapping
 ├─ "what failure mode / bias?"            → fallacy-bias-spotting
 ├─ "how much should I update?"            → bayesian-updating
 ├─ "what do you mean by X?"               → socratic-elenchus
 ├─ "what's the strongest counter?"        → steelman-red-team
 ├─ "how confident, and are you calibrated?"→ calibration-forecasting
 └─ "which option bets best under uncertainty?" → decision-analysis
Unsure → thinking-router (this skill) scores and shortlists.
```
