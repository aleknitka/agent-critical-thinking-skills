# Provenance — Argument Mapping

## Traces

- Toulmin, S. (1958) *The Uses of Argument* — claim/grounds/warrant/backing/qualifier/rebuttal.
- Walton, D. (2008) *Informal Logic* — scheme structure and critical questions.
- Ennis, R. (1987/1996) — argument appraisal and CT dispositions.
- Facione core skill: *analysis* as argument-structure analysis.

## Limits

- No parser is logic; `scripts/argmap.py` labels heuristically, not semantically.
- Validity tags are judgments about the stated warrant, not formal proof.
- A valid argument can still have false premises — soundness is separate from validity.
